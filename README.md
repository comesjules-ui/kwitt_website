# Kwitt website

Website van Kwitt, de app om spullen te lenen bij je buren. Nederlands en Frans, met video en inschrijving voor de testgroep (die komt in Supabase, tabel `waitlist`).

- `index.html`: de startpagina
- `privacy.html`: de privacyverklaring
- `CNAME`: het domein `kwitt.taalkaart.be`

Online via GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
De app zelf staat in de repo `kwitt`.
